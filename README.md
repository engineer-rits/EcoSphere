# GreenCampus

A standalone, responsive front-end website built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a separate GitHub repository for this website.
2. Upload `index.html`, `style.css` and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for the published link to appear in the Pages section.

## Notes
This is a front-end demonstration. Any events, clubs, contacts or sample content should be checked and replaced with accurate campus information before public use. Mood and selected-action demos use browser `localStorage`; they are not shared with other users.
